# 👾 CWE-197 — Numeric Truncation Error

> **Sayısal kırpma hatası.** Geniş bir sayı dar bir yere konur. Sığmayan üst
> bitler sessizce atılır. Geriye kalan, aynı sayının küçük bir parçasıdır — ve
> hiçbir şey şikâyet etmez.

| | |
|---|---|
| **Resmî ad** | Numeric Truncation Error |
| **Üst sınıf** | [CWE-681](./cwe_681.md) — Incorrect Conversion between Numeric Types |
| **Nerede doğar** | [13 · Arithmetic Unit](../salterden_bilgisayara/13_arithmetic_unit.md#16-bitlik-1-tek-tel-değildir) — genişlik meselesi |
| **Aynası** | [CWE-194](./cwe_194.md) — ters yön: dar → geniş (işaret uzatma) |

---

## Sığmayan Bitler Nereye Gider

[194](./cwe_194.md) dar bir sayıyı genişletirken **boş kalan bitlere ne
konacağını** soruyordu. Burada ters yöndeyiz: geniş bir sayı dar bir yere
giriyor ve soru şu — **sığmayanlara ne olacak?**

Cevap: atılırlar.

```c
int   i = 300;      /* 0000 0001 0010 1100 */
char  c = i;        /* alt 8 bit kalır:  0010 1100  →  44 */
```

```
  300  =  0000 0001 0010 1100
              └┬─┘  └───┬───┘
           atılır    kalan  =  44
```

Kırpma, [CWE-190](./cwe_190.md)'ın (taşma) yakın akrabasıdır ama aynı şey
değildir:

| | ne olur |
|---|---|
| **CWE-190** taşma | sayı **kendi tipinin** sınırını aşar, başa döner |
| **CWE-197** kırpma | sayı **başka bir tipe** taşınırken üst bitleri atılır |

İkisinde de sonuç "beklenenden küçük bir sayı"dır, ama biri hesapta, diğeri
kopyalamada doğar.

> 🔑 Kırpmanın en sinsi tarafı **sessizliğidir.** Ne bir hata döner, ne bir bayrak
> kalkar, ne derleyici varsayılan ayarla uyarır. Atama başarılı görünür — yalnızca
> içindeki sayı artık başka bir sayıdır.

---

## Küçülen Sayı Kontrolü Aldatır

Tehlikeli hâli, kırpmanın **kontrol ile kullanım arasında** olmasıdır.

```c
int uzunluk = istekten_oku();        /* 65536 geldi */

if (uzunluk > sizeof(buf)) return HATA;   /* 65536 > 16 → HATA döner, iyi */
```

Buraya kadar sorun yok. Ama kontrol ile kullanım farklı genişlikte tiplerle
yapılırsa:

```c
int            uzunluk = istekten_oku();   /* 65536 */
unsigned short kisa    = uzunluk;          /* alt 16 bit → 0 */

if (kisa > sizeof(buf)) return HATA;       /* 0 > 16 değil → GEÇER */
memcpy(buf, veri, uzunluk);                /* ama kopya 65536 baytlık */
```

Kontrol **kırpılmış** değere, kullanım **tam** değere bakıyor. İkisi aynı sayı
sanılıyordu; değiller.

> ⚠️ Bu ailenin ortak cümlesini tekrar et: *kontrol vardı ama işe yaramadı.*
> [190](./cwe_190.md) sırası yanlış (taşmış sayıya soruldu) · [839](./cwe_839.md)
> yarısı eksik (yalnız tavana bakıldı) · [367](./cwe_367.md) anı yanlış (araya
> değişim girdi) · **197 genişliği yanlış** (soru dar, kullanım geniş).

## Gerçek Hayatta

Bu zayıflığın en somut örnekleri **protokol ve dosya başlıklarında** çıkıyor,
çünkü oralarda alan genişlikleri sabittir ve kod onları kendi tiplerine
kopyalamak zorundadır.

Deponun exploit tarafında bunun uygulamalı hâli zaten yazılı:
[binary_exploitation/11 · Integer Bug'ları](../binary_exploitation/11_integer_bug_truncation_signedness.md)
— **Utumno 4** seviyesi doğrudan truncation üzerine kurulu, **Maze 7**'de ise
ELF başlığından okunan 16 bitlik bir alan doğrudan okuma boyu olarak kullanılıyor.

Aynı dersteki avcı sorusu burada da geçerli:

> **Boy/sınır kontrolü hangi tiple yapılıyor?** Kontrol `word` ya da `byte`
> üzerindeyse, kullanım daha geniş bir tipteyse — arada kırpma vardır.

Tarihsel ölçekte en bilinen akrabası **Y2K**'dır: yıl alanı iki haneye kırpıldığı
için 2000, 1900'den ayırt edilemiyordu. Aynı kalıp — bilgiyi taşıyan alan,
bilginin kendisinden dardı.

---

## Nasıl Önlenir

- **Kırpmadan önce sığıyor mu diye sor.** Bu ailenin tek gerçek savunması bu:

  ```c
  if (uzunluk < 0 || uzunluk > USHRT_MAX) return HATA;
  unsigned short kisa = (unsigned short)uzunluk;
  ```

- **Kontrol ile kullanımda aynı tipi kullan.** Vakaların çoğu "aynı değer iki
  farklı genişlikte dolaşıyor" cümlesiyle başlıyor. Bir kez tip seç, her yerde onu
  taşı.
- **Genişliği belli tipler kullan.** `uint16_t`, `int32_t`, `size_t`. `int`in kaç
  bit olduğu platforma göre değişir; bu belirsizlik kırpmayı görünmez kılar.
- **Derleyiciye söylet.** `-Wconversion` daraltan atamaları uyarıya çevirir.
  Varsayılan olarak kapalıdır.
- **Dış kaynaktan gelen boyutlara iki kez bak.** Ağdan, dosyadan ya da
  kullanıcıdan gelen her uzunluk alanı, kendi tipine girmeden önce sınanmalıdır.
